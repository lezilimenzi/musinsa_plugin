# Report generation

Every card must include:

- a representative display keyword;
- a verified full-body look;
- connected products;
- source IDs supporting the keyword and selection.

Do not invent sales, conversion, inventory, popularity, or ranking claims.

Outputs:

- `reports/look_first_cards.md`
- `reports/exposure_reason_report.md`
- `reports/evidence_table.md`
- `reports/validation_report.md`
